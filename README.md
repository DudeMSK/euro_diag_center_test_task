# Справочник МКБ-10

Тестовое задание: Express API с in-memory кэшем и Vue 3 интерфейс для просмотра
справочника диагнозов.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

- Frontend: <http://localhost:5173>
- Backend: <http://localhost:3000>
- Endpoint: `GET http://localhost:3000/api/v1/dictionaries/icd10`

Проверки:

```bash
npm test
npm run typecheck
npm run build
```

## Как работает backend

- Первый запрос при пустом кэше запускает имитацию чтения БД длительностью ровно
  1000 мс. Готовые данные сохраняются в памяти процесса.
- Запросы 2 и 3 получают данные из кэша. Каждый 4-й запрос атомарно увеличивает
  серверный счётчик, очищает кэш и снова читает данные из БД.
- `DictionaryCache` хранит единственный `inFlight` Promise. Параллельные запросы
  при пустом кэше подписываются на него, поэтому несколько таймеров и чтений БД
  не создаются.
- Наличие активного клиента проверяется внутри callback таймера через
  `request.destroyed` и `response.writableEnded`. Если отключились все ожидающие
  клиенты, результат не кэшируется.
- Маркер `source` равен `db` для участников тяжёлой загрузки и `cache` для
  мгновенного ответа из памяти.

Счётчик считает запросы, принятые endpoint. Инкремент и проверка `% 4` находятся
в одном синхронном middleware-блоке, поэтому другие callbacks Node.js не могут
вклиниться между этими операциями. Оборванное соединение не запускает повторную
мутацию или откат счётчика — это исключает дублирование порядкового номера при
конкурентных запросах.

## Как работает защита UI

`useIcd10Dictionary` присваивает каждому запросу возрастающий id. Перед новым
запросом предыдущий `AbortController` вызывается через `abort()`, а обновлять
реактивное состояние разрешено только Promise с актуальным id.

В `finally` флаг `loading` сбрасывается только если завершившийся запрос всё ещё
является активным. Там же очищаются сильные ссылки на Promise и controller. В
`onUnmounted` id инвалидируется, активный запрос прерывается, а ссылки удаляются.
`AbortError` считается штатной веткой управления, не показывается как сетевая
ошибка и не пробрасывается дальше.
